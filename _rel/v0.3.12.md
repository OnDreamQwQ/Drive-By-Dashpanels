**Minecraft 1.21.1 / NeoForge 21.1.x** ・ Dashpanels 2.x + Drive By Wire 0.3.0+（Create 6.0.10+ 可选，仅用于界面图标）

## 这一版修了什么

**面板遥控界面里，准星、选择框、模块指示器、数值终于都在面板之上了。**

根因不在深度测试，也不在混合模式，而在提交顺序：面板模型的顶点由 Dashpanels 按 render type 分批塞进 `MultiBufferSource`，而 `endBatch()` 无参版**只结束最后一种** shared type —— 所有 shared 类型共用同一个底层缓冲。剩下的批次留到帧末才提交，正好落在叠加层之后，于是被面板盖住。

现在面板画完当场把缓冲排空（反射 `startedBuilders`，反复调无参 `endBatch()` 直到为空），叠加层再画就稳稳在最上面。

## 安装

放进 `mods/`。依赖：

| 模组 | 版本 | 必需 |
|---|---|---|
| Dashpanels | 2.0+ | 是 |
| Drive By Wire | 0.3.0+ | 是 |
| Create | 6.0.10+ | 否（仅界面图标） |

## 已知限制

- 面板必须在客户端加载范围内（约 128~160 格），否则提示「面板不在客户端加载范围内」。
- 拖拽类模块退化为按住后拖动（不是点一下变一档），`ESC` 结束操控。
- 不同种类面板（地面 + 墙面 + 吊顶）混在一套控制台时，按真实空间位置散着摆，不会自动归成一个平面。
- 线宽是绘制时状态：我们的黄框与 Dashpanels 的悬停白框同批提交，所以悬停白框也会变粗到 2.5px。
